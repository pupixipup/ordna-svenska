# Ordna

Статичный сайт для изучения слов по карточкам. Первый модуль содержит 41 карточку из [Quizlet: Шведский B1/B2](https://quizlet.com/se/1220047069/%D1%88%D0%B2%D0%B5%D0%B4%D1%81%D0%BA%D0%B8%D0%B9-b1b2-partikelverb-och-prepositioner-flash-cards/).

## Запуск

Папка `dist` — готовый сайт без сборки. Для локального просмотра запустите `npm run dev`. На статическом хостинге укажите `dist` как корневую папку.

## Добавление модулей

1. Создайте папку `dist/modules/<имя-модуля>` с файлом `cards.json` по образцу `dist/modules/help-verbs/cards.json`.
2. Добавьте модуль в `dist/modules/index.json` с `id`, `title`, `subtitle` и `path`.
3. Сохраните изменения и повторно опубликуйте папку `dist`.

Каждая карточка в исходном JSON — пара `["термин", "перевод"]`. Примеры и комментарии к обеим сторонам можно добавить в редакторе сайта. Изменения и прогресс сохраняются в `localStorage` конкретного браузера. Для переноса на другое устройство используйте кнопки **Экспорт** и **Импорт**. Если хотите сделать свои аннотации постоянной частью модуля для всех пользователей, замените пару на объект с полями `id`, `term`, `definition`, `termNote`, `definitionNote`.

## Публикация через GitHub Pages

Создайте публичный репозиторий GitHub и отправьте в него содержимое этой папки. В настройках репозитория откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует папку `dist` при каждом коммите в `main`. Команда сборки не требуется.

Публичный сайт доступен по адресу `https://<владелец>.github.io/<имя-репозитория>/` после успешного запуска workflow. Для обновления сайта измените файлы модуля и отправьте новый коммит в `main`.
